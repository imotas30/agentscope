# 前端开发约定

本文件适用于当前前端目录及其子目录。

## 必须使用组件

- 前端修改必须优先复用现有业务组件和 `src/components/ui` 中的 shadcn/Radix 组件。
- 禁止在业务页面中用手写 `div`、`span`、CSS 和点击事件重新实现已有组件的界面或交互。
- 下拉选择使用 `SelectField` / `Select`；可自由输入的候选选择使用 `AutocompleteInput`；按钮、复选框、标签页、表格、提示、折叠和确认框使用对应的公共组件。
- 表单和内容容器优先使用 `Field`、`Card`、`Item`、`Empty` 等组件，避免在页面中堆叠 `div` 拼装界面。
- 现有组件无法满足需求时，先组合或扩展公共组件，再由页面调用。必要的基础 HTML 结构应封装在组件内部。
- 组件替换必须保留原有业务行为，并检查键盘操作、焦点、禁用状态、表单草稿、深浅主题和窄屏表现。
